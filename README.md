# プライバシーポリシー

suzuran works（運営責任者：Mochizuki Jun。以下「当管理者」といいます。）は、当管理者が提供するアプリケーション「猫部屋育成」（英語名：Idle Cat Room。以下「本アプリ」といいます。）における利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

【1. 取得または利用する情報】
本アプリは、次の情報を取得または利用することがあります。

（1）端末内に保存する情報
・利用言語、音量その他の設定情報
・猫の名前、所持アイテム、進行状況その他のゲームデータ

これらの情報は原則として利用者の端末内に保存され、当管理者のゲームデータ保存用サーバーには送信されません。本アプリをアンインストールすると、端末内に保存された情報は削除されます。ただし、端末またはOSのバックアップ機能により保存される場合があります。

（2）本アプリの機能提供に伴い送信される情報
・アプリ名、アプリバージョンおよびOS種別
・端末の機種、OSの名称およびバージョン
・IPアドレス、通信日時その他の通信ログ

これらの情報は、現在時刻の取得、最新バージョンの確認、通信障害の調査、不正利用の防止その他本アプリの提供および保守のために利用されます。

（3）Unity Remote ConfigおよびUnity Authenticationにより取り扱われる情報
本アプリは、最新バージョンの確認等のためにUnity Technologiesが提供するUnity Remote ConfigおよびUnity Authenticationを利用します。これらのサービスでは、IPアドレス、インストール固有ID、ユーザーID、匿名のPlayer ID、端末情報等が取り扱われることがあります。利用者による氏名やメールアドレスを用いたアカウント登録は行いません。

Unity Remote Config Privacy Overview
https://docs.unity.com/remote-config/privacy-and-consent/overview

Unity Privacy Policy
https://unity.com/legal/privacy-policy

（4）広告配信に伴い取り扱われる情報
本アプリは、広告配信のため、グリーエックス株式会社が提供する広告配信サービス「アドフリくん」および同サービスと連携する広告ネットワークを利用します。広告の表示、クリック等に伴い、広告識別子（IDFAまたはGoogle Advertising ID）、ユーザーエージェント、IPアドレス、端末情報、所在国情報、広告の表示・クリック等に関する情報が、グリーエックス株式会社および連携する広告ネットワーク事業者へ自動的に送信・保存されることがあります。

これらの情報は、広告の配信、広告成果の測定、不正利用の防止、広告内容の最適化等のために利用されます。取り扱われる情報、提供先、保存期間およびオプトアウト方法の詳細は、アドフリくんおよび各広告ネットワーク事業者のプライバシーポリシーをご確認ください。

アドフリくん プライバシーポリシー
https://adfurikun.jp/adfurikun/cms/detail/code/9998

海外利用者向けアドフリくん プライバシーポリシー
https://adfurikun.jp/adfurikun/cms/detail/code/9997

（5）スクリーンショットおよび共有情報
本アプリの撮影機能で作成した画像は、利用者が共有操作を行った場合に限り、共有用ファイルとして端末内の本アプリ専用領域へ一時的に保存され、利用者が選択したSNSその他の外部アプリへ渡されます。当管理者が当該画像をサーバーへ送信または保存することはありません。共有後の情報には、共有先サービスの利用規約およびプライバシーポリシーが適用されます。

【2. 利用目的】
当管理者は、取得した情報を次の目的で利用します。
・本アプリの機能提供、維持および改善
・ゲームデータおよび利用者設定の端末内保存
・現在時刻および最新バージョン情報の提供
・広告の表示、最適化および成果測定
・障害調査、セキュリティ確保および不正利用の防止
・利用者からのお問い合わせへの対応

【3. 第三者への送信および提供】
当管理者は、次の場合を除き、取得した利用者情報を第三者へ提供しません。
・本ポリシーに記載した外部サービスまたはSDKの利用に必要な場合
・利用者本人の同意がある場合
・法令に基づく場合
・人の生命、身体または財産の保護のために必要であり、本人の同意を得ることが困難な場合

当管理者は、外部サービスまたはSDKの選定および利用にあたり、各提供事業者の情報管理体制を確認し、適用法令および本ポリシーに沿った情報の保護に努めます。

【4. 情報の保存期間および削除】
端末内のゲームデータおよび設定情報は、利用者が本アプリをアンインストールするまで保存されます。共有用画像は新たな共有用画像の作成時に上書きされることがあります。

当管理者が管理する通信ログは、本アプリの運用、障害調査およびセキュリティ確保に必要な期間に限り保存し、利用目的を達成した後に削除または匿名化します。外部サービスで取り扱われる情報の保存および削除については、各提供事業者のプライバシーポリシーが適用されます。

【5. 利用者による選択および削除の申出】
利用者は、端末またはOSの設定から広告識別子の利用制限、追跡許可の変更その他のプライバシー設定を行うことができます。端末内のゲームデータは、本アプリのアンインストールにより削除できます。

当管理者が管理する情報、またはUnity Authenticationにより発行された匿名のPlayer IDに関する確認もしくは削除を希望する場合は、「8. お問い合わせ」に記載する方法でご連絡ください。対象情報を特定するため、端末やアプリに関する情報の提供をお願いする場合があります。

【6. 未成年者の利用】
未成年者が本アプリを利用する場合は、必要に応じて親権者その他の法定代理人の同意を得た上で利用してください。当管理者は、適用される法令および各ストアの年齢関連ポリシーに従って情報を取り扱います。

【7. 本ポリシーの変更】
当管理者は、法令の改正、本アプリの機能または利用する外部サービスの変更その他合理的な必要がある場合、本ポリシーを変更することがあります。重要な変更を行う場合は、本アプリ内、各ストアの掲載ページその他適切な方法で周知します。変更後の本ポリシーは、周知時に定める適用開始日から効力を生じます。
